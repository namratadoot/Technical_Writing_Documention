# Technical_Writing_Documention

## About This Repository

This repository contains documentation and notes on the topics covered in the Technical Writing course.

It provides an organized collection of concepts, commands, examples and practical information related to documentation tools and version control.

## Topics Covered

### 1. LaTeX
LaTeX is a document preparation system used to create structured documents.

Topics include:
- Introduction to LaTeX
- Document Structure
- Mathematical Notations
- Equations and Matrices
- Tables and Lists
- Colours, Figures and Pictures

[Explore LaTeX](./01-LaTeX/README.md)

### 2. Beamer
Beamer is a LaTeX document class used for creating presentations and slides.

Topics include:
- Introduction to Beamer
- Frames and Slides
- Bullet Points
- Overlays and Transitions

[Explore Beamer](./02-Beamer/README.md)

### 3. Doxygen
Doxygen is an open-source documentation generator used to generate documentation from source code.

Topics include:
- Introduction to Doxygen
- Features
- Documentation Comments
- Common Commands and Tags
- Configuration
- Output Formats

[Explore Doxygen](./03-Doxygen/README.md)

### 4. Google Docs
Google Docs is a cloud-based word processor that supports document creation and collaboration.

Topics include:
- Introduction and Features
- Collaboration and Sharing
- Comments and Suggestions
- Version History
- Exporting and Publishing

[Explore Google Docs](./04-Google-Docs/README.md)

### 5. Git
Git is a version control system used to track changes in files and projects.

Topics include:
- Creating Repositories
- Tracking and Staging Files
- Commits and Commit History
- Comparing Changes
- Branching and Merging

[Explore Git](./05-Git/README.md)

### 6. GitHub
GitHub is a platform used to host Git repositories and collaborate with developers.

Topics include:
- Creating and Connecting Repositories
- Cloning Repositories
- Pushing and Pulling Changes
- Branch Collaboration
- Pull Requests
- Developer Workflow

[Explore GitHub](./06-GitHub/README.md)

## Purpose

The purpose of this repository is to organize the concepts taught in the Technical Writing course and maintain them as structured documentation for learning and reference.
