
# Google Docs – Notes

## 1. Introduction

Google Docs is a cloud-based word processor.
- Part of Google Workspace.
- Supports live collaborative editing.
- Documents can be accessed from any device.
- Supports comments, suggestions, version history, templates and integrations.

## 2. Key Features

- Real-time multi-user collaboration.
- Rich formatting using styles and headings.
- Supports tables, images, drawings, links and equations.
- Comments and suggestions for review.
- Version history to track and restore changes.
- Import and export in different file formats.

## 3. Collaboration and Sharing

- Click **Share** to invite collaborators through email or a link.
- Set permissions:
  - Viewer
  - Commenter
  - Editor
- Add, resolve and assign comments.
- Use Suggesting mode for tracked edits.
- Collaborators can see live cursors and changes.
- Integrated chat supports live discussions.

## 4. Version History

- Google Docs automatically saves changes.
- Open **File → Version history** to view previous versions.
- Restore an earlier version when required.
- Give names to important versions, such as submission or approval.

## 5. Exporting and Publishing

Documents can be downloaded in formats such as:
- PDF
- DOCX
- ODT
- HTML
- RTF
- TXT

Other options:
- Publish documents to the web.
- Integrate with Google Slides and Google Sheets.

## 6. Best Practices

- Follow a consistent style guide and use templates.
- Organize content using headings and a table of contents.
- Assign reviewing and editing roles.
- Resolve unnecessary comments and suggestions.
- Keep backups and export important versions.

## 7. Practical Activity

1. Create a Google Doc.
2. Share it with a classmate.
3. Try headings, comments and suggestions.
4. Insert a table and an image or diagram.
5. Open version history and restore an earlier version.

## 8. Summary

Google Docs is useful for general documentation, proposals and notes. Its major strengths are real-time collaboration, formatting, sharing and version history.
